# Mettre Noob LOL en ligne (gratuit)

L'appli est un simple site : GitHub Pages l'héberge gratuitement à partir de ce dépôt.

## Activer GitHub Pages
1. Sur la page du dépôt : onglet **Settings** → menu **Pages** (à gauche).
2. *Source* : **Deploy from a branch**. *Branch* : **main**, dossier **/ (root)** → **Save**.
3. Attends 1 à 2 minutes et recharge : l'adresse apparaît, de la forme
   `https://carottejy.github.io/NoobLol/`

## Installer sur le téléphone
- **Android (Chrome)** : ouvre l'adresse → menu ⋮ → « Installer l'application ».
- **iPhone (Safari)** : ouvre l'adresse → bouton Partager → « Sur l'écran d'accueil ».

Au premier lancement il faut internet (pour télécharger les données de Riot). Ensuite l'appli marche aussi hors connexion.

## Mises à jour automatiques
L'appli vérifie toute seule s'il existe une nouvelle version (au lancement, au retour sur l'app, puis toutes les 30 min). Si oui, un bandeau « Nouvelle version disponible » apparaît : **Mettre à jour** recharge l'app sans perdre tes favoris, notes ni ta partie en cours.

Pour publier une mise à jour : modifie les fichiers du dépôt et **augmente le numéro dans `version.js`** (c'est ce qui déclenche la détection).

Les données des champions et objets se mettent à jour seules à chaque nouveau patch de League of Legends, sans rien publier.
